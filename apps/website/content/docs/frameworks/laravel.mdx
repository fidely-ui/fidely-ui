## Get started with our template

The easiest way to get started is to use our **Laravel v13 + Inertiajs + React** template.  
It comes preconfigured with Panda CSS, Fidely UI (v2) and theme support.

```bash
npx gitpick https://github.com/fidely-ui/fidely-templates/tree/main/laravel-template
```
