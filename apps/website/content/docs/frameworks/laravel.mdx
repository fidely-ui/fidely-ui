## Get started with our template

The easiest way to get started is to use our **Laravel v12 + Inertiajs + React** template.  
It comes preconfigured with Panda CSS, Ark UI, Fidely UI v2 and theme support.

```bash
npx degit https://github.com/fidely-ui/laravel-template
```
